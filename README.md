# Autonomous Guardian Gun System

AI-powered autonomous sentry system using:
- OpenCV
- MediaPipe Pose
- TensorFlow Lite
- Arduino
- PyFirmata

## Features
- Human pose detection
- Threat classification
- Manual RC mode
- Telegram alerts
- Servo-based targeting

## Hardware
- Arduino
- Servo motors
- Webcam/IP camera
- Laptop/PC
